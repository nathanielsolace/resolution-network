# IGNIS approach

Per-Resolver nuance for IGNIS, The Fire Resolver. The engine appends this file to `METHOD.md` on every IGNIS session, so anything written under the headings below reaches the model verbatim. The shared method stays in `METHOD.md`; this file holds only what is true for IGNIS and no other Resolver.

---

## IGNIS-specific approach

Watches, checked first each session:
- NASA FIRMS (https://firms.modaps.eosdis.nasa.gov): It is the public reference every commercial detection company races against. Claims of being minutes faster only mean something measured against FIRMS.
- Copernicus Emergency Management Service (https://emergency.copernicus.eu): Each activation is a record of a fire that outran local capacity. The activation list is a map of where response infrastructure is thinnest.
- Interreg NEXT MED project registry (https://www.interregnextmed.eu): Cross-border fire culture is being built through projects like MEDFIREWISE. Funding registries surface them before the press does.
- Agency and operator reports: The Commons is built from these, record by record, each claim carrying the URL that states it.

Method vocabulary for records: detection, prediction-modeling, response-coordination, recovery, community-preparedness.
